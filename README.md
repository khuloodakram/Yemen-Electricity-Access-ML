Yemen Electricity Access Prediction Using Machine Learning
Project overview
This project uses survey responses from Yemen to explore factors associated with household electricity access and build machine-learning models to classify electricity access levels.
The target is derived from the survey question:
Q1: On average, how many hours per day do you have access to electricity?
The binary target is defined as:
Low electricity access (0): 0–6 hours per day
Higher electricity access (1): more than 6 hours per day
The notebook compares classification models and evaluates performance using metrics that account for class imbalance.
Dataset
The project was developed using the cleaned survey file:
Renewable Energy Survey_Final_Clean.xlsx
The dataset is described as a survey dataset on solar energy, electricity access, and governance in Yemen. Place the Excel file in the project folder before running the notebook.
Data note: The dataset is not included in this repository. Make sure you have permission to share any data before publishing it. Do not upload private, confidential, or identifying survey information.

Methods and workflow
The notebook's workflow includes:
Loading and inspecting the survey data.
Cleaning data and handling missing values.
Preparing the binary target from daily electricity-access hours.
Excluding the target and selected basic electricity-access questions (Q1–Q4) from the main feature set to reduce target leakage.
Preparing features for machine learning.
Comparing classification models, including Support Vector Machine (SVM), Extra Trees, and Random Forest.
Evaluating models with accuracy, balanced accuracy, Macro-F1, a classification report, and a confusion matrix.
Using cross-validation and feature analysis to help assess model performance.

Setup
1. Create an environment (recommended)
python -m venv .venv
Activate it:
Windows
.venv\Scripts\activate
macOS / Linux
source .venv/bin/activate
2. Install dependencies
python -m pip install --upgrade pip
pip install -r requirements.txt
3. Add the dataset
Put Renewable Energy Survey_Final_Clean.xlsx in the location expected by the notebook. If the notebook uses a different path, update the data-loading cell to match your file location.
4. Run the notebook
Start Jupyter:
jupyter notebook
Open Yemen_Electricity_Access_ML_Improved.ipynb and run the cells from top to bottom. Alternatively, upload the notebook and dataset to a suitable hosted notebook environment and adjust the file path as needed.
Reproducibility and responsible use
Run the notebook from the first cell to the last so preprocessing and evaluation steps are performed consistently.
Use the same validation strategy when comparing models.
Do not use the target column or information derived directly from it as model inputs.
Check class-level metrics, not accuracy alone.
Survey-based model results show associations in the collected data; they do not by themselves establish causation or represent every household in Yemen.
Do not publish personal or confidential information from survey records.
